- C'est la petite histoire d'un renard qui regarde le soleil.
  Lentement la nuit tombe et le petit renard se fait rejoindre
  par ses amis les animaux. Ils regardent ensemble le coucher
  de soleil et s'endorme collé les uns avec les autres. Pendant
  qu'ils dorment, une petite luciole vien se poser sur un nénuphar
  ce qui réveille le petit renard curieux qui va la voir stupéfaite.
